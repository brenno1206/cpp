<h2>REPOSITÓRIO DE APRENDIZADO DE C++ REFERENTE A DISCIPLINA DE LINGUAGENS DE PROGRAMAÇÃO</h2>

---

<h3>Execução</h3>
```
g++ -std=c++20 code.cpp -o out.exe
```

---

<h3>CONFIGURACAO DO VSCODE</h3>


1. Pressione <b>Ctrl + Shift + P</b> no VS Code.  
2. Digite e selecione: Preferences: <b>Open User Settings (JSON)</b> (ou abra as configurações do workspace).
3. Adicione ou altere a linha do padrão C++ para c++20 (ou c++23):  
```
"C_Cpp.default.cppStandard": "c++20"
```
4. Salve o arquivo e reinicie o VS Code (ou feche e abra a janela com <b>Ctrl + Shift + P</b> -> <b>Developer: Reload Window)</b>.
